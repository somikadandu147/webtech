WHAT IS HTML?

HTML INTRO
  • HTML stands for Hyper Text Markup Language.
  • HTML is the standard markup language for creating Web pages
  • HTML describes the structure of a Web page
  • consists of a series of elements

    SYNTEX:

    SYNTEX is the set of rules that defines how code must be written.Syntax rules to put tags,symbols and words in the correct order.
  • You start with an opening tag
  • You write your content in the middle: Hello World
  • You end with a closing tag containing a forward slash : /

    HTML Document

  • The [!DOCTYPE html] declaration defines that this document is an HTML5 document
  • The [html] element is the root element of an HTML page
  • The [head] element contains meta information about the HTML page
  • The [title] element specifies a title for the HTML page
  • The [body] element defines the document's body, and is a container for all the visible contents.
  • The [h1] element defines a large heading
  • The [p] element defines a paragraph
